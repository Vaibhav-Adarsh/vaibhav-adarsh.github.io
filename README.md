## Contact Form

The contact form connects to a separate Node.js and Express.js backend hosted on Render. Email delivery is handled through the Resend API.

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Vaibhav-Adarsh/vaibhav-adarsh.github.io.git
cd vaibhav-adarsh.github.io
```

Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

**Note:** The contact form requires the separately deployed backend to be available.
